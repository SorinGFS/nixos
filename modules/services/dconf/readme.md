# Dconf

[default.nix](default.nix) enables the shared dconf backend with `programs.dconf.enable`; GNOME, Files and KeePass import it for their preferences. See [NixOS configuration syntax](https://nixos.org/manual/nixos/stable/#sec-configuration-syntax).

Preference owners define native schema attributes and explicit GVariant types where required: see [GNOME desktop](../../desktop/gnome/readme.md), [Shell](../../desktop/gnome/shell/readme.md), [Dash to Panel](../../desktop/gnome/shell/dash-to-panel/readme.md), [wallpaper](../../desktop/gnome/wallpaper/readme.md), [Files](../../applications/files/readme.md), and the [KeePass shortcut](../../applications/keepass/gnome/readme.md). Integer settings require a schema-specific constructor such as `lib.gvariant.mkInt32` or `mkUint32`; empty arrays require `mkEmptyArray` with their element type. The [Nixpkgs GVariant library](https://github.com/NixOS/nixpkgs/blob/nixos-26.05/lib/gvariant.nix) defines these constructors. See the [data and desktop presets guide](../../../tutorial/nix.md#data-desktop-presets-and-host-composition).

[GNOME](../../desktop/gnome/readme.md) and [Firefox](../../applications/firefox/readme.md) defaults are unlocked and existing user overrides win. [VSCodium](../../applications/vscodium/readme.md) instead seeds missing writable files once; existing files remain user-owned. Generated immutable results and writable preferences have [different lifecycles](../../../tutorial/nix.md#immutable-results-and-writable-application-data).
