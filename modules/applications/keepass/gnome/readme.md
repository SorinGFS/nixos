# KeePass GNOME shortcut

When the KeePass module and GNOME are selected, this child imports dconf and supplies unlocked Ctrl+Alt+A Auto-Type shortcut defaults from [index.json](index.json). It does not enable GNOME. Existing user settings take precedence. See [NixOS modules](https://nixos.org/manual/nixos/stable/#sec-writing-modules) and the [launcher](../readme.md).
