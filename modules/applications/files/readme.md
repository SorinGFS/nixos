# Files

This module installs Nautilus, associates folder opening with it, imports dconf and supplies unlocked list-view defaults from [index.json](index.json). Existing user settings take precedence; [GNOME](../../desktop/gnome/readme.md) explains session changes. Apply source edits through the [local update workflow](../../readme.md#apply-local-configuration-and-update-the-whole-system). See [NixOS configuration syntax](https://nixos.org/manual/nixos/stable/#sec-configuration-syntax).
