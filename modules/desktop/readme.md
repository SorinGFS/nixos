# Desktop composition

The desktop composition imports GNOME, shared Nix, services, security, Bash and application modules. It disables sudo and leaves the host responsible for accessible root authentication. It does not select the separately exported power, virtualisation or KeePass policies. See [module integration](../readme.md) and [NixOS modules](https://nixos.org/manual/nixos/stable/#sec-writing-modules).
