# Wallpaper

[index.json](index.json) names the included regular image and zoom mode. The module converts its relative asset path to an immutable store URI for light and dark backgrounds. Replace the asset and filename together, then follow the [local update workflow](../../../readme.md#apply-local-configuration-and-update-the-whole-system). Existing user choices override the default. Display scaling is [user-managed](../readme.md#display-scaling). See [Nix builtins](https://nix.dev/manual/nix/2.34/language/builtins.html).
