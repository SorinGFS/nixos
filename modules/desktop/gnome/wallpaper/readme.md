# Wallpaper

[default.nix](default.nix) defines the zoom mode and converts the included image's relative path to an immutable store URI for light and dark backgrounds. Replace the asset and update that path together. Existing user choices override the default. Display scaling is [user-managed](../readme.md#display-scaling). See [Nix builtins](https://nix.dev/manual/nix/2.34/language/builtins.html).
