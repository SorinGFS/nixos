# GNOME Shell defaults

[default.nix](default.nix) supplies unlocked favorites, enabled extensions and the ordered app grid as native schema attributes. It builds the grid's array of dictionaries with typed variant positions. Existing user choices override defaults; source edits require the [local update workflow](../../../readme.md#apply-local-configuration-and-update-the-whole-system). See [Nix builtins](https://nix.dev/manual/nix/2.34/language/builtins.html) and [GNOME preferences](../readme.md).
