# GNOME Shell preferences

GNOME Shell preference defaults are maintained in `settings/shell/index.json` and applied as user dconf settings. Source edits take effect after [project activation](../../system/readme.md#apply-native-configuration-edits); existing user values take precedence.

[GNOME desktop preferences](../desktop/readme.md) covers inspecting and changing current-session values and user defaults. Dash to Panel has its own [preference and lifecycle instructions](../dash-to-panel/readme.md).

Source: [settings/shell/default.nix](../shell/default.nix).
