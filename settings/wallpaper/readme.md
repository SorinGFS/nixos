# Wallpaper

The wallpaper defaults are maintained in `settings/wallpaper/index.json`, which names the included image. Wallpaper changes pair a replacement regular image asset with its relative filename, followed by [project activation](../../system/readme.md#apply-native-configuration-edits). The native configuration applies the selected image as the GNOME background; existing user values take precedence.

[GNOME desktop preferences](../desktop/readme.md) covers user defaults and GUI changes.

Source: [settings/wallpaper/default.nix](../wallpaper/default.nix).
