# Files preferences

The Files (Nautilus) preference defaults are maintained in `settings/files/index.json` and applied as user dconf settings. Source edits take effect after [project activation](../../system/readme.md#apply-native-configuration-edits); existing user values take precedence.

[GNOME desktop preferences](../desktop/readme.md) covers current-session values, user defaults, and manual capture of GUI changes in project sources.

Source: [settings/files/default.nix](../files/default.nix).
